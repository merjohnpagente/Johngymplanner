# Johns Fit Planner

React + Vite + Capacitor gym planner. Includes Push, Pull, two leg days, upper body, active recovery, and rest day; exercises with sets/reps; completed-exercise tracking; searchable exercise library; custom exercises; and body-weight log. Progress saves locally on the device.

## Build Android APK using only your phone
1. Upload all files and folders to a GitHub repository. Keep `.github/workflows/build-apk.yml`.
2. Open the repository's Actions tab and enable Actions if asked.
3. Choose **Build Android APK** and tap **Run workflow**.
4. Download the `johns-fit-planner-apk` artifact after the build completes.
5. Extract the downloaded ZIP and install `app-debug.apk`. Android may ask you to allow installs from the browser or file manager.

This is a debug APK for testing, not a signed Play Store release. A network connection is required for the cloud build. No laptop or Android Studio is needed.

## Local dev
`npm install` then `npm run dev`

Training plans are general examples. Warm up, choose manageable loads, use controlled technique, adapt to available equipment, and stop if you experience sharp pain.
